# GitHub 个人主页第一版设计

## 目标

为 GitHub 用户 `scy2004` 创建并公开发布一个最小可用的个人主页，正式访问地址为：

`https://scy2004.github.io/`

这一版只负责建立稳定的网址和后续可扩展的页面基础，不提前编写个人经历、研究方向、项目列表或联系方式。

## 发布方式

- 创建公开仓库 `scy2004/scy2004.github.io`。
- 使用 GitHub Pages 的用户主页约定，从默认分支发布根目录静态文件。
- 使用纯 HTML 与 CSS，避免引入构建工具和依赖，让后续修改与维护尽可能简单。
- 暂不购买或绑定独立域名；未来可以在不重做网站的情况下绑定个人域名。

## 页面内容

主页为一个单屏、响应式的建设中页面，包含：

- 页面标题：`scy2004`。
- 简短状态文字：`Personal website coming soon.`。
- 一个指向 GitHub 个人资料的链接。
- 基本网页标题、描述和站点图标。

不加入虚构的个人姓名、照片、学校、机构、研究成果、社交账号或联系方式。

## 视觉方向

采用克制、现代、偏研究者主页的样式：清晰排版、充足留白、高对比度配色，并在手机和电脑上正常显示。第一版不使用图片、动画或复杂交互。

## 验收标准

- `https://scy2004.github.io/` 可以公开访问。
- 页面在常见桌面和手机宽度下无横向溢出，文字清晰可读。
- GitHub 链接可以正常打开。
- 页面不包含未经用户确认的个人信息。
- 仓库结构足够简单，后续可以直接添加个人介绍、研究、论文和项目内容。

## 后续范围

后续内容填写作为独立阶段进行。本次不包含独立域名购买、访问统计、联系表单、后台、数据库或博客系统。
